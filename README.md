## Features

- Advanced prompt engineering libraries and negative prompt presets optimized for rapid, high-quality AI image generation and professional workflows.
- Workflow automation scripts to streamline repetitive batch processing, upscaling (hires.fix), and output directory organization tasks.
- Custom model, VAE, and LoRA configuration profiles for enhanced output consistency, character consistency, and specific artistic styling.
- Quick-switch macros for seamless navigation between different generation tabs, extensions (e.g., ControlNet, ADetailer, Regional Prompter), and settings panels.
- Pre-configured sampling method and scheduler profiles for efficient balancing of generation speed, step count, and visual fidelity.
- Comprehensive documentation and step-by-step setup guides for all included tools, configuration files (e.g., `ui-config.json`), and modules.
- Integration examples and bridge scripts for third-party creative applications (e.g., Adobe Photoshop, Blender, After Effects).
- VRAM and system resource optimization configs (e.g., `xformers`, `medvram`) for faster inference and reduced memory footprint during complex generations.
- Ready-to-use inpainting, outpainting, and image-to-image prompt sets with automated masking and denoising strength routines.

## Requirements

- Windows 10/11 (or Linux)
- NVIDIA GPU with sufficient VRAM (recommended)
- Installed Stable Diffusion interface (Automatic1111, ComfyUI, or SD.Next)

## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1`) to integrate the custom prompt libraries, extension configurations, and macros directly into your Stable Diffusion `webui-user.bat` environment or `ComfyUI` custom nodes folder. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced node/prompt usage, refer to the `GUIDE.md` file included in the archive.
